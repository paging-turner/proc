For now, we will have to manually test a bunch of features. This file exists to list out the features and manual steps to take in order to test each feature.

------------------------------------------
001 Connect and Undo
    1. Create process
    2. Create another process
    3. Connect processes
    4. Undo
    EXPECT: Only the wire should disappear.
    5. Redo
    EXPECT: The wire is back.



------------------------------------------
002 Connect and delete write
    1. Create process
    2. Create another process
    3. Connect processes
    4. Delete the new wire.
    EXPECT: To only have the two processes, and the wire connecting them should be gone.
    5. Undo
    EXPECT: The wire re-appears and is still connected to the two processes.



------------------------------------------
003 Delete one of two wires
    1. Create three processes
    2. Connect the first to the third
    3. Connect the second to the third
    4. Delete the wire from the first connection
    NOTE: The test can be generalized, as long as you don't delete the *last* wire.



------------------------------------------
004 Multi-select wire connection
    1. Create three processes
    2. Select two of the processes
    3. Perform a multi-select connection to the non-selected process
    EXPECT: Should have the two selected processes connected to the third process.



------------------------------------------
005 Delete connected process
    1. Create two processes
    2. Connect the processes
    3. Delete one of the processes
    EXPECT: There should only be the non-deleted process present.



------------------------------------------
006 Delete two wires
    1. Create three processes
    2. Connect the first to processes to the third
    3, Select both wires
    4. Delete both wires at once
    EXPECT: Both wires should be deleted



------------------------------------------
007 Move a wire
    1. Create three processes
    2. Connect the first process to the second
    3. Move the end of the wire connected to the second process to the third process
    EXPECT: The wire should connect the first process to the third
